# To-Do App

A simple and easy-to-use to-do application built with Flutter and Dart as part of the Digital Skills Training Program (DSTP).

---

## Overview

This application helps users organize daily tasks and items efficiently. It provides a clean interface to create, track, edit, and remove entries with instant UI updates.

---

## Features

- Add Tasks: Easily create new items and add them to your list.
- View List: View all existing tasks displayed in organized cards.
- Edit Tasks: Update and modify task details whenever needed.
- Delete Tasks: Quickly remove completed or unwanted tasks with a single tap.
- Clean Interface: Minimal Material Design layout with clear action buttons and a floating add button.

## Getting Started

### Prerequisites

Make sure you have Flutter installed on your machine:
- Flutter SDK (^3.11.4 or higher)
- Dart SDK
- An emulator, browser, or connected physical device

### Installation & Run

1. Navigate to the project directory:
   ```bash
   cd to_do_app
   ```

2. Install packages:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
